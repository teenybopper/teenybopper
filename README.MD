### 🚀 Latest Project Spotlight

### [⚡ WorkPilot AI — Local Agentic Work Orchestration Platform](https://workpilot-ai-dun.vercel.app/)

A privacy-first, on-device AI assistant and multi-agent workspace orchestrator that bridges the gap between meetings, documents, and real-world task execution:

- 🎙️ **MeetOps**: Real-time meeting audio capture (Tauri v2 + Rust), local speech recognition (`faster-whisper`), and multi-speaker diarization (`pyannote.audio`).
- 📄 **DocOps**: Deep document parsing (`Docling`) of PDFs, DOCX, and PPTX with entity extraction & contract diffing.
- 🧠 **Cross-Source Intelligence**: Unified RAG via ChromaDB that detects discrepancies between what was agreed in calls vs. written in documents.
- ⚡ **ActionOps**: Translates decisions into real-world actions via **Model Context Protocol (MCP)** adapters (Jira, Slack, Teams, GDocs) with 1-click **Human-in-the-Loop** review.

🔗 **Links**: [Live Web Application](https://workpilot-ai-dun.vercel.app/) · [GitHub Repository](https://github.com/teenybopper/WorkpilotAI)
