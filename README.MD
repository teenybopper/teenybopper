### 🚀 Latest Project Spotlight

### [⚡ WorkPilot AI — Agentic Work Orchestration Platform](https://workpilot-ai-dun.vercel.app/)

An on-device, privacy-first AI platform connecting meetings and documents directly to execution:

- 🎙️ **MeetOps**: Real-time meeting audio capture (Tauri v2 + Rust), local transcription (`faster-whisper`), and multi-speaker diarization (`pyannote.audio`).
- 📄 **DocOps**: Deep document parsing (`Docling`) of PDFs, DOCX, and PPTX with entity extraction & contract diffing.
- 🧠 **Cross-Source Intelligence**: Unified RAG via ChromaDB with meeting-to-spec conflict detection.
- ⚡ **ActionOps**: Generates actionable workflows via **Model Context Protocol (MCP)** adapters (Jira, Slack, Teams, GDocs) with 1-click **Human-in-the-Loop** review.

🔗 **Links**: [Live Web Application](https://workpilot-ai-dun.vercel.app/) · [GitHub Repository](https://github.com/teenybopper/WorkpilotAI)
